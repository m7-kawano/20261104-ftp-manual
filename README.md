# 星屑ドッジ — STARDUST DODGE

降りそそぐ星屑の弾幕をかわし続ける、ブラウザ向けの弾幕系シューティング（回避）ゲームです。
フレームワーク不使用の素の HTML / CSS / JavaScript（ES Modules）で作られており、ビルド不要でそのまま Cloudflare Pages に公開できます。

## 遊び方

| 操作 | 内容 |
| --- | --- |
| 十字キー / WASD | 移動 |
| Shift | 低速移動（かすり判定の範囲を表示） |
| マウス | 機体がカーソルを追従 |
| タッチ | 画面上のどこでもドラッグすると機体が相対移動（指で機体が隠れません） |
| Esc / P | ポーズ（タブ切替時も自動ポーズ） |
| M | サウンドのオン/オフ |

- ゲーム開始時に「簡単」「普通」「難しい」から難易度を選択します。
- 機体中央の白い点だけが当たり判定です。被弾するとライフを失い、0 になるとゲームオーバー。
- 30 秒ごとにステージを移動します。移動中はワープ演出とともにスコア・ボーナス・現在のランクが表示され、次のステージでは配色・BGM の調・弾幕の種類と密度が変わります。

## スコアとランク

- 生存 1 秒ごとに `100 × 難易度倍率 × ステージ倍率` 点（ステージ倍率は 1 ステージごとに +0.25）
- 弾の近くをかすめる「かすり」で `20 × 難易度倍率` 点
- ステージクリアで `1000 × ステージ数 × 難易度倍率` 点 ＋ 画面上の残弾 1 発につき `5 × 難易度倍率` 点
- 難易度倍率：簡単 ×1.0 / 普通 ×1.6 / 難しい ×2.5

| ランク | スコア |
| --- | --- |
| S | 150,000 以上 |
| A | 80,000 以上 |
| B | 40,000 以上 |
| C | 18,000 以上 |
| D | 7,000 以上 |
| E | 2,000 以上 |
| F | それ未満 |

難易度ごとのベストスコアはブラウザ（localStorage）に保存されます。

## ファイル構成

```
public/
├── index.html        画面（タイトル / 難易度 / HUD / ステージ移動 / ポーズ / リザルト）
├── css/style.css     UI とアニメーション
├── js/main.js        画面遷移・HUD・リザルトなど UI 制御
├── js/game.js        ゲームループ・弾・発射源・自機・描画
├── js/patterns.js    弾幕パターン（リング / 自機狙い / スパイラル / 花 / 波 / 加速 / 炸裂 / 十字）
├── js/config.js      難易度・ランク・ステージ配色などの設定
├── js/audio.js       Web Audio API による効果音と BGM の手続き生成（音声ファイル不要）
├── js/input.js       キーボード・マウス・タッチ入力
├── js/starfield.js   背景の星空
├── favicon.svg
└── _headers          Cloudflare Pages 用のセキュリティ / キャッシュヘッダ
```

## ローカルで動かす

ES Modules を使うため、ファイルを直接開くのではなく簡易サーバ経由で開いてください。

```bash
python3 -m http.server 8000 --directory public
```

ブラウザで http://localhost:8000 を開きます。

## Cloudflare Pages での公開

1. Cloudflare ダッシュボード → Workers & Pages → 作成 → Pages → Git に接続 でこのリポジトリを選択
2. ビルド設定
   - フレームワークプリセット：なし
   - ビルドコマンド：（空欄）
   - ビルド出力ディレクトリ：`public`
3. 保存してデプロイ

Wrangler を使う場合：

```bash
npx wrangler pages deploy public --project-name stardust-dodge
```
