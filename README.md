# 星屑ドッジ / STARDUST DODGE

撃たずに避ける、ブラウザ向け弾幕ドッジゲームです。HTML / CSS / JavaScript(ネイティブ ES Modules)のみで作られており、フレームワークもビルド工程もありません。

## 遊び方

降りそそぐ弾幕をかいくぐり、できるだけ長く生き残ってハイスコアとランクを目指します。自機は撃ちません。**当たり判定は自機中央の小さな点**です(低速移動中はより明るく表示されます)。

### 操作

| 入力 | 動作 |
| --- | --- |
| 矢印キー / WASD | 8方向移動 |
| Shift | 低速(フォーカス)移動 |
| Esc / P | ポーズ |
| Enter / Space / 矢印 | メニューの決定・選択 |
| M | サウンドのミュート切替 |
| マウス | プレイ画面上で動かすと自機が追従(最大速度あり) |
| タッチ | 画面のどこでもドラッグ。指の移動量だけ自機が動く(相対操作)。画面右上のボタンでポーズ、右下の FOCUS で低速移動 |

タブが非表示になった場合やウィンドウのフォーカスが外れた場合は、自動でポーズします。

### 難易度

| 難易度 | ライフ | スコア倍率 | 弾の密度 / 速度 |
| --- | --- | --- | --- |
| 簡単 (EASY) | 3 | ×1.0 | 控えめ |
| 普通 (NORMAL) | 2 | ×1.6 | 標準 |
| 難しい (HARD) | 1 | ×2.5 | 濃く速い |

被弾するとライフが減り、一定時間の無敵(点滅)と周囲の弾の消去が入ります。ライフが 0 になるとゲームオーバーです。

### ステージ

30 秒ごとにステージが進みます(エンドレス)。ステージごとに色のテーマと弾幕の組み合わせが変わり、進むほど弾の数・速度・同時に動く弾幕の数が増えます。ステージ切り替え中(約3秒)は弾がきらめきに変わり、自機への当たり判定はありません。

### スコアとランク

- **生存スコア**: `100 × (1 + 0.3 × (ステージ - 1)) × 難易度倍率` 点 / 秒
- **グレイズ**: 弾に当たらず至近距離をかすめると加点(ステージが進むほど高得点)
- **ステージクリアボーナス**: `1000 × ステージ × 難易度倍率` + 変換した弾の数に応じた加点

| ランク | 必要スコア |
| --- | --- |
| S | 120,000 以上 |
| A | 55,000 以上 |
| B | 25,000 以上 |
| C | 12,000 以上 |
| D | 5,000 以上 |
| E | 1,500 以上 |
| F | それ未満 |

目安: HARD で約 3 分、NORMAL で 4 分以上の生存で S ランクに届きます。ベストスコアは難易度ごとに `localStorage` へ保存されます。

## ローカルで実行

ES Modules を使うため `file://` ではなく HTTP サーバー経由で開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

`?debug=1` を付けると `window.__game` が公開され、開発用に時間スキップなどが行えます(例: `__game.game.debugSkip(30)`)。

## Cloudflare Pages へのデプロイ

静的サイトなのでビルドは不要です。

1. このリポジトリを GitHub などにプッシュする。
2. Cloudflare ダッシュボードの **Workers & Pages** → **Create** → **Pages** → **Connect to Git** でリポジトリを選ぶ。
3. ビルド設定:
   - **Framework preset**: None
   - **Build command**: (空欄 / なし)
   - **Build output directory**: `/`
4. **Save and Deploy** を押す。

`_headers` により、セキュリティヘッダー(CSP など)とキャッシュ設定が適用されます。Web フォントは Google Fonts から読み込みます(オフラインでは代替フォントで表示)。

CLI の場合: `npx wrangler pages deploy . --project-name stardust-dodge`

## ファイル構成

```
index.html        画面(DOM オーバーレイ)
css/style.css     スタイル・アニメーション
js/config.js      調整用の定数(難易度・ランク・ステージテーマ)
js/main.js        起動・リサイズ・固定タイムステップのループ
js/game.js        シミュレーションと描画
js/patterns.js    弾幕パターン(9種類)
js/sprites.js     弾・光の事前描画スプライト
js/starfield.js   背景(星・星雲)
js/input.js       キーボード / マウス / タッチ入力
js/audio.js       Web Audio による効果音と BGM(音声ファイルなし)
js/ui.js          メニュー・HUD・リザルトの制御
_headers          Cloudflare Pages 用ヘッダー設定
```
